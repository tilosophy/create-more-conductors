# 0.1.0-beta.1

First beta, following the owner-accepted alpha 2.

- Twelve casing appearances alongside the original Andesite conductor.
- Accepted gameplay and conductor skins unchanged from alpha 2.
- Includes the circular conductor badge in the mod list and workshop branding for the listing.
- Player guide, installation instructions and third-party credits included.

Minecraft 1.21.1; Java 21; NeoForge build target 21.1.262; Create 6.0.10; Steam 'n' Rails community port 0.3.0-beta.2+neoforge-mc1.21.1. Install on server and clients.

Real multiplayer testing is deferred. Blackstone/Platinum have not had automated creation tests with their full optional dependency stacks. See [validation](VALIDATION.md).
