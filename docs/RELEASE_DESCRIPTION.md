# Create: More Conductors

Give your railway crew a little more character.

Create: More Conductors adds twelve casing-inspired appearances to Steam ’n’ Rails conductors, alongside the original Andesite conductor. Place a supported casing and use a conductor’s cap on it to bring your new crew member to life.

Build a brass station crew, copper workshop helpers, or a mixed-material team for your trains. Body material and cap colour are independent, so your conductors can match their workplace while keeping their own coloured caps.

## Familiar conductors, more variety

These are the same Steam ’n’ Rails conductors, with their existing model, animations and behaviour. The addon changes their appearance; it does not add jobs, abilities, flight, glowing bodies or material refunds.

The twelve new appearances are **Brass, Copper, Train, Shadow, Radiant, Zinc, Blaze, Sturdy, Industrial, Overburden, Blackstone and Platinum**. Some require optional casing-provider mods; see the player guide. The original Andesite appearance remains available.

The custom skins are recolours of the original conductor texture, preserving its eyes, panel layout and shading. Steam ’n’ Rails special named skins retain priority.

## Requirements

- Minecraft Java Edition **1.21.1**, Java **21**.
- NeoForge **21.1.262 or later within 21.1**; the build target is 21.1.262.
- Create **6.0.10**.
- Steam ’n’ Rails community port **0.3.0-beta.2+neoforge-mc1.21.1**.
- Install More Conductors on **both the server and every client**.

The dependency versions are deliberately restricted. This release does not target Forge, Fabric, other Minecraft versions, or the original Steam ’n’ Rails releases for older Minecraft versions.

No new world or new chunks are needed. Optional casing mods are not required to use the core variants. More Conductors does not add casing recipes; availability depends on the installed mods and datapacks.
